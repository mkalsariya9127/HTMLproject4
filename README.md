# 🌐 Corporate Business & Health Awareness Web Platform

A comprehensive multi-page corporate website template featuring user authentication (login/registration), public health safety information, and business contact services.

---

## 🚀 Live Demo & Preview
👉 **[View Live Website on GitHub Pages](https://mkalsariya9127.github.io/HTMLproject4/)**

---

## 🌐 Included Pages
- **Home (`index.html`):** Business overview, core mission, and service highlights.
- **Health & Safety Guide (`covid.html`):** Public awareness resources, preventative guidelines, and wellness notices.
- **User Login (`login.html`):** Clean and secure user login form interface.
- **User Registration (`register.html`):** Account sign-up form with input validation fields.
- **Contact Us (`contact.html`):** Direct communication inquiry form and location map.

---

## ✨ Key Features
- **Semantic Structure:** Built following standard HTML5 semantic tags for strong accessibility.
- **Authentication UI:** Ready-to-connect login and registration frontend views.
- **Responsive Styling:** Mobile-friendly layouts for all pages.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic multi-page structure
- **CSS3:** Custom layouts, forms, buttons, and typography

git clone https://github.com/mkalsariya9127/HTMLproject4.git
